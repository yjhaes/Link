# 以短码作为短链接映射的主键

> 当前实现说明（2026-10-01）：本文保留阶段 1 的决策背景。当前代码已采用 [ADR-0002](0002-permuted-auto-id-base62.md) 的 MySQL 发号与有界双射编码，映射仍以完整短码为主键；下文“尚未实施阶段 2”描述的是原决策时的状态。实现现状见 [架构说明](../architecture.md)，本说明不替代测试验收。

第一阶段按短码查找映射，且每次创建都会产生独立记录，因此选择固定 8 位 `short_code` 作为主键，不再增加自增数字 ID 和第二个短码唯一索引。这样单表结构和碰撞处理更直接；代价是对外短码与内部记录标识绑定，将来若有其他表引用映射或需要改变短码形式，迁移主键会更费力。已分配的短码会一直保留且不复用。

阶段 2 的已确认设计见 [ADR-0002](0002-permuted-auto-id-base62.md)；当前代码仍采用本 ADR 描述的第一阶段结构，尚未实施阶段 2。
