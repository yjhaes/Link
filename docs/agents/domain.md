## 布局

本项目采用 single-context：

- 根目录 `CONTEXT.md`：领域概念和术语表。
- `docs/adr/`：架构决策记录。

## 阅读规则

探索代码前，读取 `CONTEXT.md` 和相关 ADR。
如果存在 `CONTEXT-MAP.md`，按其指引读取相关上下文的文档。

文档不存在时，直接继续工作。领域建模技能会在明确术语或决策后按需创建文档。

## 术语与决策

使用 `CONTEXT.md` 定义的术语，避免替换为它明确排除的同义词。
缺少概念时，判断是否属于领域文档缺口，并记录给领域建模工作。

方案与现有 ADR 冲突时，明确指出对应 ADR 和重新讨论的理由。
