## 目标

新增独立的 `/admin.html` 管理工作台，复用现有 HTTP API，支持创建短链接、按短码设置启用状态及查看最近 30 个上海统计日的 PV、UV 和访问日志。页面不引入前端框架或构建步骤。

## 交互与约束

- 桌面使用左侧导航，窄屏导航移至内容上方；沿用现有青绿配色。
- 创建区支持永久与按分钟设定有效时长，显示短链、短码及到期信息，并提供复制、打开和转入管理操作。
- 状态初始未知；只有收到服务端确认后才显示本次操作状态。
- 访问统计默认最近 7 个上海统计日，可查询最近 30 日内的自定义范围；访问日志每页 20 条并使用服务端游标加载。
- 管理令牌只在页面运行期间保留，作为 `X-Internal-Token` 请求头发送，不写入持久化存储或 URL。
- 变更代码、日期或令牌时取消过期的统计请求并清空旧结果；操作提交期间避免重复提交。
- 显示异步统计、匿名访客 UV、采集开关、鉴权及业务拒绝、统计繁忙和缓存协调未确认等状态。

## 范围

只新增管理页面资源并补充 README 使用说明。不新增后端 API、账号、全量映射列表、删除或原始网址编辑能力。
