# 04: 管理者查询日期范围 PV/UV 与日趋势

**What to build:** 内部管理者通过受令牌保护的聚合接口，得到单短码日期范围的已记录 PV、整体去重 UV 和逐日趋势；已有禁用/过期映射可以查询历史，缺数据与查询失败有不同的明确结果。建立明细及清理验收可复用的日期窗口和查询边界。

**依赖说明：** 01 — 现有启用/禁用操作受统一管理令牌保护；02 — 合法跳转同步记录匿名访客访问日志
