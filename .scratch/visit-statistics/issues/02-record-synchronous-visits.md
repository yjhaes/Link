# 02: 合法跳转同步记录匿名访客访问日志

**What to build:** 开启采集并配置有效访客密钥后，每个作出正常跳转决定的 GET 同步尽力保存一条访问日志，返回原有 302 及适当的访客 Cookie。记录器只收到已经冻结时间、识别身份并脱敏的独立事件，缓存命中与共享加载请求都逐请求记录。

## Acceptance criteria

- [ ] 采集默认关闭，关闭时无事件、日志或访客 Cookie；开启需要独立有效 HMAC 密钥与版本，所有实例采用一致配置，显式非法配置明确失败。
- [ ] 新增符合规格的独立日志表：自增行 ID、唯一 BINARY(16) 事件 ID、大小写敏感短码、UTC 毫秒 occurred_at、上海 stat_date、BINARY(32) 访客摘要及版本和可空脱敏元数据；索引支持聚合、分页及清理，不增加外键或映射计数字段。
- [ ] 建立显式归属的统计专用池，最多 4 个连接、minimumIdle=0，初始写入容量 2；核心 DataSource、mapper、JDBC 模板、发号、事务管理器和数据库初始化仍归核心，不重复初始化或删除现有数据。
- [ ] 采用规格中的连接池、验证、建连、socket、语句和行锁超时起始值；统计连接预检失败不增加新的启动网络硬依赖，不承诺消除核心原有依赖。
- [ ] 跳转用例返回原始 URL 与最终逐请求检查时冻结的决定时刻，同一时刻检查过期与计算统计日；共享加载等待者各自定时，入口不事后重读 Clock。
- [ ] 决定前的拒绝及错误、HEAD、创建、查询和状态维护不生成事件或 Cookie；决定后统计等待到期/禁用仍完成原 302，跨午夜提交按发生日记录。
- [ ] sl_visitor 使用规范 22 字符 Base64URL 的 128 位安全随机值；合法单值复用，缺失、非法或无法确定的同名多值重建并立即参与本次 UV，不回退 IP。
- [ ] Cookie 固定 30 天、不续期，host-only、Path=/s、HttpOnly、SameSite=Lax，HTTPS 配置 Secure；不回传与首次并发的偏差明确保留。
- [ ] 访客 HMAC 输入含用途、版本、大小写敏感短码和随机字节；原始 Cookie 不进入事件或存储。相同身份跨实例稳定，不同短码摘要不同，紧急新密钥用新版本。
- [ ] 对端 IP 按 IPv4 /24、IPv6 /48 脱敏，正确处理 mapped 地址，忽略外部代理头的身份声明；UA 清理并限 512 字符，Referer 只留合法规范化 host，缺失/畸形置空，不阻断跳转。
- [ ] 客户端再次 GET 产生新事件；同一事件 ID 内部重放不新增行，不把其他数据库异常当作正常重复；不保存原始秘密、完整 IP/Referer、URL 副本或整组请求头。
- [ ] 写入准入立即判断，没有容量就跳过；日志失败或确认不确定的基础处理继续 302，不重试，不加入核心事务或调用 Redis 统计命令，成功和失败均释放资源。
- [ ] 以 HTTP/Cookie 和真实 MySQL 验证正常 GET、同身份多次访问、大小写/短码隔离、hit/miss、两个请求共享一次加载、跨日和排除请求；核心创建、跳转及状态事务回归可验证。
- [ ] 不新增统计查询端点；本任务通过响应与持久化结果独立验收，后续查询不成为其前置。
