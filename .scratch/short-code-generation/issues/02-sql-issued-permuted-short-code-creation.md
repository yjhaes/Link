# 02: 用 SQL 发号生成可跳转的短链接

## What to build

匿名创建者沿用现有接口创建短链接，得到按已确认规则由 MySQL 发号 ID 生成的 4 至 8 位短码。发号与映射分别提交，允许未使用的发号 ID；多个应用实例共享一个 MySQL 主写库时，成功创建的短码仍唯一且可以立即跳转。

## Acceptance criteria

- [ ] 每次创建先由追加式 MySQL 发号表提交唯一 ID，再用阶段 2 ADR 固定的仿射混淆、Base62 字符表和最短 4 位补齐规则生成最终短码；映射表只保存完整短码作为主键，不保存数字 ID。
- [ ] 创建成功时维持现有 `201`、短码、完整短链接与到期时刻的接口契约；返回的短链接可直接跳转，页面显示、复制和打开行为继续可用。
- [ ] 发号成功后若编码或映射失败，已发 ID 不回收也不复用，已提交发号记录保留，但不产生部分完成的短链接映射；两次插入不使用跨表创建事务。
- [ ] 只对短码主键冲突重新发一个 ID 并重试一次，首次冲突留下异常记录；两次都冲突时返回 `500 SHORT_CODE_GENERATION_FAILED` 且不创建新映射，其他数据库错误不按碰撞重试。
- [ ] 编码器单元测试锁定固定向量、字符集、4 至 8 位边界、非正 ID、最大允许 ID 和越界失败；计算不得因整数乘法溢出而改变结果。
- [ ] MockMvc 与真实 MySQL 接口集成测试覆盖创建与跳转、分开提交后的发号空洞、一次重试及耗尽、大小写精确比较，并验证共享同一 MySQL 主写库的并发创建不产生重复短码；不将测试结果解释为固定 QPS 承诺。
- [ ] 原有随机 8 位生成及最多四次插入尝试的测试预期已更新；所有与阶段 1 保留行为相关的测试继续通过。
